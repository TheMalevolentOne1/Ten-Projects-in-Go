# Task List Command-Line Interface
## Warning (Fix Later)
The data/data.json file **MUST** begin with '[' and end with ']' *OTHERWISE* data will be **OVERWRITTEN** into empty json file.
## Usage Examples
```bash
$ tasklist help
Usage: 
HELP MENU
Key:
<> Required [] Optional

Commands:
tasklist all
tasklist add <TASK_NAME> [DESCRIPTION] if Desc Empty then Empty Body.
tasklist remove <TASK_ID>
```
